# Copier Portal Dashboard

This is a web dashboard for managing and analyzing copier/printer usage reports.

## Tech Stack
- Frontend: React.js
- Backend: Express.js (Node.js)
- Database: Neon PostgreSQL

## Deployment
- Hosted on Vercel: https://copier-portal.vercel.app/
- Database hosted on Neon: https://console.neon.tech/app/projects/still-tree-24177023

## Setup & Testing
1. Configure env variables in `backend/.env`.
2. Run database migration using `node backend/migrate_data.js`.
3. Run verification using `.\verify.ps1`.
