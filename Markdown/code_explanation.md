# อธิบายโค้ดระบบประมวลผลรายงานเครื่องถ่ายเอกสาร (`run_report.py`)

เอกสารฉบับนี้จัดทำขึ้นเพื่ออธิบายรายละเอียดการทำงานระดับซอร์สโค้ด (Source Code Explanation) ของไฟล์ [run_report.py](file:///d:/PythonScript2/run_report.py) โดยแยกตามส่วนโครงสร้างและฟังก์ชันต่าง ๆ ของโปรแกรม

## 1. ไลบรารีและโมดูลที่ใช้งาน (Imports)

โปรแกรมใช้ทั้งโมดูลมาตรฐานของ Python (Built-in Modules) และไลบรารีภายนอก (Third-party Library):

```python
import csv, os, re, shutil, stat
from datetime import datetime
from openpyxl import Workbook
from openpyxl.styles import Font, Alignment, PatternFill, Border, Side
from openpyxl.utils import get_column_letter
```

| โมดูล | วัตถุประสงค์ในการใช้งาน |
| :--- | :--- |
| **`csv`** | จัดการอ่านและเขียนข้อมูลในฟอร์แมต CSV (Comma-Separated Values) |
| **`os`** | จัดการระบบไฟล์ เช่น ค้นหาไฟล์ ตรวจสอบสิทธิ์ของไฟล์ และสร้างโฟลเดอร์ |
| **`re`** | ใช้ Regular Expression สำหรับทำความสะอาดข้อมูลที่เป็นสัญลักษณ์พิเศษและเว้นวรรค |
| **`shutil`** | ใช้ในการคัดลอกไฟล์ย้ายข้ามระบบ เช่น การส่งสำเนาไฟล์ดิบและทำ Backup |
| **`stat`** | ใช้ร่วมกับการเปลี่ยน Permission ของไฟล์ให้เป็นแบบอ่านอย่างเดียว (Read-only) |
| **`datetime`** | เก็บข้อมูลวันที่และเวลา ณ ขณะที่รันระบบ เพื่อจัดรูปแบบ Timestamp ของ Log และไฟล์รายงาน |
| **`openpyxl`** | ไลบรารีสำหรับสร้าง จัดรูปแบบสไตล์ ฟอนต์ สีสัน และส่งออกไฟล์รายงานแบบ Excel (.xlsx) |

## 2. โครงสร้างการตั้งค่าระบบ (Config Section)

โปรแกรมกำหนดตัวแปรตั้งค่าระบบไว้ในส่วนบนของโค้ด เพื่อความสะดวกในการปรับปรุงภายหลัง:

```python
BASE_DIR = os.path.dirname(os.path.abspath(__file__))
INBOX_DIR          = os.path.join(BASE_DIR, "00_Inbox")
ALLOWED_SOURCE_DIR = INBOX_DIR

RATE_TABLE = {
    "print_bw":    0.50,   # บาท/แผ่น
    "print_color": 1.00,   # บาท/แผ่น
    "copy_bw":     0.50,   # บาท/แผ่น
    "copy_color":  1.00,   # บาท/แผ่น
    "scan":        0.00,   # บาท/แผ่น (ฟรี)
}

REQUIRED_COLS = [
    "User", "Name",
    "Black & WhiteTotal(Printer)",
    "ColorTotal(Printer)",
    "Black & WhiteTotal(Copier/Document Server)",
    "Full ColorTotal(Copier/Document Server)",
    "ScannerTotal(Scanner)",
]
```

* **`BASE_DIR` / `INBOX_DIR` / `ALLOWED_SOURCE_DIR`**: ระบุพาธตั้งต้นของระบบและตีกรอบการนำเข้าไฟล์เฉพาะจากโฟลเดอร์ `00_Inbox` เท่านั้น เพื่อความปลอดภัย
* **`RATE_TABLE`**: กำหนดอัตราบริการพิมพ์ ก๊อปปี้ และสแกน
* **`REQUIRED_COLS`**: ลิสต์ระบุชื่อหัวคอลัมน์ของไฟล์ CSV ต้นทางที่โปรแกรมจะสแกนหา หากชื่อขาดหายไปขั้นตอน Validation จะล้มเหลวทันที

## 3. ฟังก์ชันการทำงานพื้นฐานและการจัดการระบบไฟล์ (Utility & File Helpers)

### `setup_folders()`
วนลูปพจนานุกรมพาธ `DIRS` เพื่อตรวจสอบและสร้างโฟลเดอร์ผลลัพธ์ทั้งหมดอัตโนมัติ

### `scan_inbox()`
สแกนหาเฉพาะไฟล์ที่มีนามสกุล `.csv` ในโฟลเดอร์ `00_Inbox` แล้วนำมาเรียงลำดับพยัญชนะเพื่อให้โปรแกรมทำงานทีละไฟล์ตามลำดับที่แน่นอน

### `backup_and_delete(csv_path, run_ts)`
1. สร้างโฟลเดอร์ย่อยใน `06_Backup` โดยระบุ Timestamp
2. คัดลอกไฟล์ต้นฉบับไปไว้ในนั้น และใช้คำสั่ง `os.chmod` ตั้งสิทธิ์เป็น Read-only เพื่อป้องกันไม่ให้ข้อมูลต้นฉบับถูกแก้ไข
3. ลบไฟล์ดิบที่ประมวลผลแล้วออกจาก `00_Inbox` เพื่อป้องกันการประมวลผลซ้ำในรอบถัดไป

### `clean_int(val)` และ `clean_str(val)`
ใช้ฟังก์ชันจากโมดูล `re` ในการล้างสัญลักษณ์ส่วนเกิน เช่น วงเล็บ `[ ]`, เครื่องหมายอัญประกาศ `"`, `'`, และช่องว่าง (White spaces) ให้เหลือเฉพาะตัวเลขหรือตัวอักษรดิบ ป้องกันการแปลงชนิดข้อมูลผิดพลาด (ValueError)

### `log(msg, level)` และ `save_log()`
บันทึกการทำงานของสคริปต์ในขณะประมวลผล พร้อมพิมพ์ออกหน้าจอ และเขียนไฟล์บันทึกเป็น Text file เก็บไว้ในโฟลเดอร์ `05_Log`

## 4. ระบบป้องกันความปลอดภัยข้อมูล (Security Control Functions)

เพื่อรองรับนโยบาย PDPA และสิทธิ์การเข้าถึงข้อมูลอย่างถูกต้อง โค้ดได้ติดตั้งกลไกความปลอดภัยไว้ดังนี้:

### `sc1_check_csv(path)`
ตรวจสอบนามสกุลของพาธไฟล์ดิบ หากไม่ได้ลงท้ายด้วย `.csv` จะถูกปฏิเสธทันที

### `sc2_check_source(path)`
แปลงพาธของไฟล์ดิบเป็น Absolute Path แล้วเช็กว่ามีจุดตั้งต้นตรงตามที่กำหนดไว้ใน `ALLOWED_SOURCE_DIR` หรือไม่ เพื่อป้องกันแฮกเกอร์โจมตีด้วยเทคนิค Directory Traversal (เช่น การอ้างอิง `../../etc/passwd` นอกโฟลเดอร์ระบบ)

### `sc4_check_not_source(out_path, src_path)`
เปรียบเทียบพาธของไฟล์ดิบและไฟล์ผลลัพธ์ที่จะเขียน หากมีพาธตรงกัน (จะบันทึกทับไฟล์เดิม) จะปฏิเสธเพื่อรักษาไฟล์ต้นฉบับให้คงอยู่ในสภาพสมบูรณ์เสมอ

### `sc5_copy_to_raw_readonly(src_path)`
คัดลอกไฟล์ดิบไปที่ `01_Raw_Report` และใช้คำสั่ง `os.chmod(dst, stat.S_IREAD | stat.S_IRGRP | stat.S_IROTH)` เพื่อถอนสิทธิ์เขียนไฟล์ ป้องกันการดัดแปลงข้อมูลย้อนหลัง

### `mask(val)`
ฟังก์ชันการทำ Data Masking สำหรับลบข้อมูลส่วนบุคคลอ่อนไหว (เช่น รหัสพนักงานและชื่อจริง) โดยการตัดเก็บเฉพาะตัวแรกและตัวสุดท้ายของข้อความ ส่วนข้อความตรงกลางจะแปลงเป็นสัญลักษณ์ `*` แทนทั้งหมด
* ตัวอย่าง: `"1770"` $\rightarrow$ `"1**0"`, `"LAMUN"` $\rightarrow$ `"L***N"`

## 5. ฟังก์ชันการประมวลผลขั้นตอนหลัก (Workflow Steps)

### Step 1: `validate(path)`
โหลดไฟล์ข้อมูลขึ้นมา ตรวจสอบมาตรการ `[SC-1]` และ `[SC-2]` สำเนาข้อมูลลงโฟลเดอร์ `01_Raw_Report` ตามระบบ `[SC-5]` และยืนยันความถูกต้องของคอลัมน์ จากนั้นอ่านข้อมูลทั้งหมดเข้าสู่ตัวแปรในหน่วยความจำ

### Step 2: `process(headers, rows)`
วนลูปแถวข้อมูลที่ได้รับมา ทำความสะอาดและแปลงชนิดข้อมูล จากนั้นเรียกฟังก์ชัน `mask` ในการปกป้องข้อมูล **`[SC-3]`** และคำนวณราคาสุทธิโดยแยกเก็บออกเป็น 2 รายการ:
* `cleaned_rows`: ตารางข้อมูลแบบ Masked สำหรับนำไปสร้าง Cleaned CSV
* `records`: พจนานุกรมจัดเก็บข้อมูลเชิงลึกของผู้ใช้เฉพาะที่มีค่าบริการมากกว่า 0 บาท สำหรับนำไปคำนวณสถิติและทำเอกสารสรุปยอด

### Step 3: `save_cleaned_csv(cleaned_rows, src_path)`
เขียนบันทึกไฟล์ข้อมูลตารางที่ Masked และคำนวณเสร็จเรียบร้อยแล้วไปไว้ที่ `02_Cleaned_Report` พร้อมเช็กมาตรการป้องกันการเขียนทับไฟล์ดิบ **`[SC-4]`**

### Step 4: `save_user_csv(records, src_path)`
เขียนสรุปยอดค่าใช้จ่ายการใช้งานรายบุคคลที่ Masked แล้วลงในตารางกลางที่โฟลเดอร์ `03_Processed_Output/user_usage_report.csv`

### Step 5: `save_markdown(records, src_name, src_path)`
คำนวณยอดรวมบริการในระบบ (ขาวดำ, สี, สแกน) และเขียนสรุปผลรายงานค่าบริการทั้งหมดให้อยู่ในฟอร์แมต Markdown บันทึกลงในไฟล์ `03_Processed_Output/copier_summary_report.md` เพื่อนำไปใช้งานด้านเอกสารสรุปผลที่อ่านง่ายบนแพลตฟอร์มต่าง ๆ

### Step 6: `save_excel(records, src_name, src_path)`
สั่งสร้างไฟล์รายงาน Excel ด้วย `openpyxl` โดยเรียกใช้ฟังก์ชันย่อยอีก 2 ฟังก์ชัน ได้แก่:
1. **`write_sheet_summary(ws, records, src_name)`**:
   - สร้างชีตสรุปรายรับ-รายจ่าย ยอดผู้ใช้บริการ และกำหนดตารางแสดงราคาสินค้าแต่ละประเภท
   - ตกแต่งสไตล์ตาราง หัวข้อ ขอบตาราง และไฮไลท์สีสันที่ออกแบบไว้ล่วงหน้า
2. **`write_sheet_detail(ws, records)`**:
   - นำรายการผู้ใช้งานในระบบทั้งหมดมาสร้างเป็นตารางข้อมูลแยกบุคคล
   - เขียนฟังก์ชันตกแต่ง เช่น การสลับสียอดแถว (สีขาวสลับสีฟ้านวล `F0F5FF`) การตรึงแนวคอลัมน์ (Freeze Pane `A3`) เพื่อให้อ่านข้อมูลตารางยาว ๆ ได้ง่าย และแสดงยอดรวมสุทธิไว้บรรทัดล่างสุด

## 6. ฟังก์ชันควบคุมการทำงานระดับบนสุด (`main()`)

เมื่อโปรแกรมถูกเรียกใช้งาน (รันโค้ด):
1. เริ่มต้นเรียกใช้ `setup_folders()` เพื่อตรวจสอบความพร้อมของระบบโฟลเดอร์
2. ค้นหาไฟล์ในกล่องรับข้อมูลเข้าโดย `scan_inbox()`
3. หากมีไฟล์ จะวนลูปประมวลผลทีละไฟล์ผ่าน Step 1 ถึง Step 6
4. เมื่อกระบวนการสร้างและเขียนบันทึกไฟล์ผลลัพธ์ของไฟล์นั้นเรียบร้อยแล้ว โปรแกรมจะเรียกฟังก์ชัน `backup_and_delete()` ทันทีเพื่อย้ายไฟล์ดิบไปที่โฟลเดอร์ Backup และเคลียร์โฟลเดอร์ Inbox
5. เมื่อจัดการครบทุกไฟล์ จะทำการเซฟ Run Log ทั้งหมดลงในเครื่อง และสรุปผลลัพธ์ของไฟล์ที่รันสำเร็จ/ล้มเหลว รวมถึงระบุเงื่อนไขความปลอดภัย (Security Controls) ที่ทำงานสำเร็จออกทางคอนโซลหลัก
